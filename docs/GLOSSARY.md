# Глоссарий предметной области

<!--
  Один термин — одно слово в коде, в БД, в UI и в разговоре.
  Термин попал сюда → именно так он называется в коде.
-->

| Термин | Определение | В коде |
|--------|-------------|--------|
| Клиент | Служба такси, совершающая исходящие звонки и оплачивающая их | `Client` |
| Партнёр | Физлицо с SIM-картами и GOIP-шлюзами, терминирующее звонки | `Partner` |
| **Канал** | **Линия исходящей связи клиента**: набор правил — разрешённые операторы, лимиты, CallerID, расписание | `Channel` |
| **Порт шлюза** | **Физический слот GOIP-шлюза**, в который вставлена SIM | `GatewayPort` |
| Шлюз | GOIP-устройство партнёра, регистрирующееся на узле АТС по SIP | `Gateway` |
| SIM | SIM-карта партнёра со своим оператором, номером и лимитами | `SimCard` |
| Узел | Сервер с установленной АТС, обслуживающий шлюзы и запись разговоров | `Node` |
| Направление | Пара «оператор и регион» из ответа `OperatorResolver`. **Не префикс:** определять оператора по префиксу запрещает [ADR-0013](adr/0013-opredelenie-operatora.md), и отдельной сущности направления нет — тарифы ссылаются на оператора и регион напрямую | — |
| Коридор цены | Установленные админом границы **стоимости эталонного вызова в 60 секунд** по тарифу партнёра. Не цена за минуту: коридор по одному числу обходится платой за соединение ([ADR-0023](adr/0023-koridory-cen.md)) | `PriceBand` |
| Цена партнёра | Цена терминации, назначенная партнёром внутри коридора | `PartnerRate` |
| Комиссия | Доля платформы в стоимости звонка | `CommissionRule` |
| Терминация | Завершение вызова на GSM-сети через SIM партнёра | — |
| Маршрутизация | Выбор шлюза и SIM для конкретного вызова | `routing` |
| Резерв | Удержание средств клиента на время звонка до фактического списания | `Reservation` |
| Проводка | Неизменяемая запись движения средств в двойной записи | `LedgerEntry` |
| CDR | Детализация завершённого вызова с зафиксированными деньгами | `Cdr` |
| Запись | Аудиозапись разговора, привязанная к CDR | `Recording` |
| Лимит | Ограничение минут или числа звонков в заданном окне времени | `LimitWindow` |
| Окно | Период, за который считается лимит: час, сутки, неделя, месяц | `window` |
| ASR | Answer Seizure Ratio — доля отвеченных вызовов от всех попыток | `asr` |
| ACD | Average Call Duration — средняя длительность отвеченного вызова | `acd` |
| MNP | Переносимость номера между операторами: префикс не определяет оператора | `mnp` |
| Овердрафт | Разрешённый клиенту отрицательный баланс | `overdraft` |
| Выплата | Перечисление заработка партнёру. Только по запросу партнёра, при достижении порога | `Payout` |
| Псевдоним партнёра | Имя, под которым партнёр виден клиенту. Личность и контакты не раскрываются | `PartnerAlias` |
| Приоритет | Порядок предпочтения партнёров в канале клиента. Равные приоритеты делят трафик поровну | `ChannelPartnerPriority` |
| Покрытие партнёра | Регионы, в которые партнёр принимает вызовы. Список закрытый, но **пустой означает «все»** ([ADR-0022](adr/0022-pokrytie-regionov.md)) | `PartnerCoverage` |
| Наценка | Доход платформы: фиксированная сумма за вызов плюс процент от стоимости | `CommissionRule` |
| Порог отключения | Число неуспешных вызовов, после которого канал, SIM или шлюз отключается автоматически | `FailureThreshold` |
| Тип шлюза | `goip` — аппаратный GOIP, `android` — телефон партнёра с приложением | `Gateway.type` |
| Требование записи | Признак канала: разговоры обязательно записываются. Исключает `android`-шлюзы из маршрутизации | `Channel.recording_required` |
| Определитель оператора | Компонент, отвечающий, какому оператору принадлежит номер: кэш, внешний lookup, план нумерации | `OperatorResolver` |
| Микроединица | Единица хранения денег: 1 рубль = 1 000 000 микроединиц. Все суммы — целые `BigInt` | `micros` |
| Маршрутный номер | Технический номер, по которому определяется оператор-получатель перенесённого номера | `routing_number` |
| БДПН | База данных перенесённых номеров. Прямой доступ требует лицензии на услуги связи | — |
| Пополнение | Зачисление средств на баланс клиента | `Payment` |

## Запрещённые синонимы

| Не использовать | Использовать | Почему |
|-----------------|--------------|--------|
| `channel` для порта шлюза | `GatewayPort` | Канал — сущность клиента, порт — сущность партнёра. Смешение ломает и модель, и интерфейс |
| `line`, `trunk` | `Channel` | Один термин на одно понятие |
| `user` для клиента или партнёра | `Client` / `Partner` | `User` — только учётная запись; у одного `User` может быть роль клиента или партнёра |
| `balance` как изменяемое поле | `LedgerEntry` | Баланс выводится из проводок, а не хранится как редактируемое значение |
| `price` без уточнения | `PartnerRate` / `ClientRate` | Цена покупки и цена продажи — разные величины, их путаница = убыток |
| `call` для записи в биллинге | `Cdr` | `Call` — процесс, `Cdr` — финансовый документ о нём |
| `sim_number` | `msisdn` | Номер SIM и ICCID — разные вещи |
| `float`/`number` для денег | `BigInt` в микроединицах | Плавающая точка теряет копейки; в биллинге это накапливается |
| Определение оператора по префиксу | `OperatorResolver` | Из-за MNP префикс не определяет оператора |
