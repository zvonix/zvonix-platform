# Контракты API

Здесь лежат спецификации внешних контрактов: OpenAPI для клиентского API,
описание вебхуков и формат обмена с узлами АТС.

Правило: контракт описывается **до** реализации и обновляется в том же изменении,
что и код. Клиенты (службы такси) интегрируются по этим файлам, поэтому расхождение
спецификации с поведением — не документационный, а продуктовый дефект.
