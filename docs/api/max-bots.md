# Боты MAX: что известно из документации платформы

Источник: <https://dev.max.ru/docs/chatbots/bots-create/create> (прочитано 2026-10-07 по ссылке владельца).
Это факты о внешней системе, а не решение: решение о боте — отдельным ADR, когда владелец выберет схему.

## Кто и как создаёт бота

- Подключение доступно **юрлицам, ИП и самозанятым — резидентам РФ**; сначала создаётся и **верифицируется профиль**
  организации, ИП или самозанятого.
- Бот создаётся **вручную** в веб-версии платформы (business.max.ru/self) или в мини-приложении «MAX для бизнеса».
  **Создания ботов через API в документации нет.**
- **Лимит ботов на профиль: организация или ИП — 5, самозанятый — 2.**
- Токен выдаётся **после модерации бота — до 48 часов по рабочим дням**.
- Название: 1–59 знаков (латиница, кириллица, цифры, без эмодзи); описание — до 200 знаков; никнейм генерируется сам.
- В полях и логотипе **запрещены** ненормативная лексика, контент 18+ и **данные других компаний**.

## Что из этого следует для схемы «свой бот у каждого клиента»

- Ботов у одного профиля не больше 5: на десятки клиентов своих ботов не хватит.
- Каждый бот — ручное создание и до 48 часов модерации: подключение клиента не станет мгновенным.
- Название и логотип бота с брендом клиента (службы такси) могут нарушить запрет на «данные других компаний».
- Значит, масштабируется только **один бот площадки (или несколько по числу лимита) с настройками на клиента**:
  приветствие, текст до и после, подпись. Решение — отдельным ADR после выбора владельца.

## Не выяснено

- Бот первым человеку не пишет: по сведениям из сторонних источников (не из документации MAX, 2026-10-07) бот пишет
  только тому, кто сам запустил диалог и дал согласие. Значит, для уведомления о заказе незнакомому пассажиру бот
  не подходит — только когда пассажир уже нажал «Запустить» у бота. Это главный довод за отправку через аккаунты.
- Лимиты отправки бота и правила по рассылкам — в документации MAX BOT API.
