# Публичные данные для сайта проекта

Без входа, только чтение. Состав и решение — [ADR-0082](../adr/0082-sayt-proekta.md). Всё, что здесь отдаётся,
видит любой посетитель сайта: поэтому только то, что владелец сам опубликовал, и агрегаты без партнёров
([ADR-0014](../adr/0014-vybor-partnera-klientom.md)).

## `GET /public/site`

Контакты и название компании — поля раздела «Сайт» в настройках площадки
([settings.md](settings.md)). Ответ кешируется на минуту (`Cache-Control: public, max-age=60`).

```json
{
  "company_name": "ООО «Звоникс»",
  "email": "hello@zvonix.com",
  "phone": "",
  "telegram": "@zvonix",
  "working_hours": "",
  "cabinet_url": "https://cp.zvonix.com",
  "site_url": "https://zvonix.com"
}
```

Пустая строка — поле не заполнено, сайт его не показывает. Ещё два поля — адреса, выведенные из адреса кабинета
(`WEB_BASE_URL`): `cabinet_url` — куда ведут «Войти» и «Подать заявку»; `site_url` — адрес самого сайта, если кабинет
стоит на `cp.<домен>` (`https://<домен>`), иначе `null`. Других полей в ответе нет.

## `GET /public/prices`

Цены «от» для клиента: самая низкая цена минуты звонка и сообщения MAX среди допущенных партнёров с общей наценкой
площадки (правило без клиента). Звонок считается как эталонный вызов в 60 секунд — с платой за соединение и минимумом,
как сравнение предложений в кабинете клиента ([ADR-0023](../adr/0023-koridory-cen.md)).

```json
{ "call_from": "12", "message_from": "0.54", "updated_at": "2026-10-12T12:00:00.000Z" }
```

- `null` — цен нет (нет общей наценки или ни у кого нет цены): сайт пишет «по запросу», а не ноль.
- Ответ держится в памяти пять минут (`Cache-Control: public, max-age=300`).
- В ответе нет партнёров, их числа, операторов и направлений: открытая поверхность даёт только агрегат
  ([ADR-0014](../adr/0014-vybor-partnera-klientom.md)).
