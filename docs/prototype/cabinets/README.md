# Образец кабинетов — утверждён 2026-09-23

Утверждённый владельцем образец нового дизайна всех трёх кабинетов и регистрации.
По нему переделываются экраны; правила, которые из него следуют, записаны
в [DESIGN.md](../../DESIGN.md) («Меню», «Окно, страница или панель»).

Живой холст с кликабельными досками: https://claude.ai/artifact/YaH8kZJzL6Rn6wJvCMaBqp
(доступ у владельца). Здесь — копия его досок один в один, чтобы образец
не зависел от внешней площадки.

|---|---|

Файлы — формат холста (`.dc.html`: разметка с подстановками `{{…}}` и логикой
в `renderVals()`), отдельно в браузере не открываются. Смотреть — на холсте;
здесь они для сверки разметки, текстов и цветов. Форматировщик их не трогает
(`.prettierignore`): он переписывает подстановки внутри `style`.

Данные выдуманные. Квадратные скобки (`[дата]`, `[срок проверки]`) — факты,
которых ещё нет.
