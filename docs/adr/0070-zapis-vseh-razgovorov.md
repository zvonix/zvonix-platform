# ADR-0070: Запись всех разговоров по умолчанию и деньги вызова в списках

- **Статус:** Принято — 2026-10-04, владелец: «всё так же нет возможности прослушать запись»,
  «стоимость звонка не отображается»
- **Дата:** 2026-10-04
- **Связано с:** [ADR-0063](0063-hranilishche-zapisey-na-diske.md), [ADR-0012](0012-mobilnoe-prilozhenie.md),
  [ADR-0014](0014-vybor-partnera-klientom.md), [ADR-0010](0010-model-billinga.md)

## Контекст

Запись разговора включалась только у линии отметкой «запись обязательна». На боевой площадке у
линии клиента она не была отмечена — узел не писал ничего, в базе записей 0, и «Прослушать» не
появлялось: функция работала, но по умолчанию была выключена, а владелец ждал её без единого
действия. Отдельно: в списках вызовов не было денег по вызову, хотя проводка `charge:<вызов>`
их хранит.

## Решение

1. **Настройка `recordings.record_all`, по умолчанию ВКЛЮЧЕНА.** Диалплан добавляет `record_session`,
   если запись требует линия **или** площадка пишет всё. Выключить можно в «Настройки площадки» →
   «Хранение»: тогда пишутся только линии с обязательной записью, как прежде. Прочие правила записи
   не меняются: срок хранения (ADR-0065), подписанные ссылки, журнал прослушиваний, права на
   прослушивание, выгрузка узлом (ADR-0063).
2. **Правило про Android не расширяется.** Линия с обязательной записью по-прежнему не идёт на
   шлюз типа `android` (запись там невозможна). Запись «по умолчанию» отказом не оборачивается:
   на таком шлюзе вызов идёт без записи.
3. **Деньги вызова — в списках вызовов**, одной выборкой по проводкам страницы
   (`BillingService.chargesForCalls`): клиенту «Стоимость» (списано), партнёру «Начислено»,
   сотруднику «Деньги» (клиент, партнёру, площадке). Нет проводки (отказ, ноль секунд) — пусто.
   Клиент не видит доли партнёра и маржи, партнёр — клиентской цены (ADR-0014): каждый получает
   только свою часть.
4. **В списке клиента у состоявшегося разговора без записи — «записи нет»**, а не молчание: человек
   видит, что запись не появилась, а не гадает, где кнопка.

## Последствия

- Записи — персональные данные: теперь они появляются у всех линий без отдельного решения клиента.
  Это решение владельца площадки; срок хранения (по умолчанию 30 суток) и журнал прослушиваний
  остаются. Для линий, где запись не нужна, площадка выключает настройку целиком (по линиям
  выключатель не вводится: «запись обязательна» остаётся единственным признаком линии).
- Объём диска растёт с числом разговоров: тревога о месте на диске (ADR-0065, ADR-0062) уже есть.
