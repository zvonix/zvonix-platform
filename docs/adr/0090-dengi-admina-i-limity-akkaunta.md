# ADR-0090: Счета и пополнение на одной странице, лимиты аккаунта MAX без спора, «СТОП» без галочки

- **Статус:** Принято — 2026-10-21; владелец: «рекомендованные лимиты спорят с лимитами тарифа… в настройках аккаунта выбираем
  тариф и ставим галочку „рекомендовано“, тогда выбранные лимиты не действуют и становятся серыми», «деньги клиентов в одном меню,
  партнёров в другом — нормально ли? пополнение без обязательного основания», «клиент не видит, какой партнёр добавляет „СТОП“»,
  «раздел „Лимиты“ у партнёра — зачем», «„Записи разговоров“ в „Деньгах“ не к месту» — ответ «да» на рекомендации
- **Дата:** 2026-10-21
- **Связано с:** [ADR-0088](0088-otchety-i-zashchita-akkauntov-max.md) (рекомендованная работа, «СТОП»),
  [ADR-0075](0075-tarify-max-nabor-uslovij.md) (тарифы MAX), [ADR-0014](0014-vybor-partnera-klientom.md) (клиент не видит партнёра),
  [ADR-0036](0036-dostup-partnyora-k-zapisyam.md) (записи), [ADR-0080](0080-edinye-limity-i-raspredelenie.md) (лимиты звонков)

## Решения

1. **Рекомендованная работа заменяет лимиты тарифа, а не складывается с ними.** Галочка у аккаунта включена — лимиты в минуту, час и
   сутки берутся из профиля площадки, лимиты тарифа не действуют; пауза между сообщениями — не меньше рекомендованной. Профиль из
   одних нулей означает «режим выключен»: действуют лимиты тарифа, как без галочки (ноль у одного предела — без ограничения по нему).
   В «Настройках» аккаунта и в таблице аккаунтов лимиты тарифа при включённой галочке показаны серыми с пометкой «не действуют».
   Прежнее правило «меньшее из двух» (ADR-0088, шаг 3) отменено. Отдельной сущности «набор лимитов» не вводится: лимиты остаются в тарифе.
2. **Строка «СТОП» добавляется ко всем сообщениям через аккаунты партнёров** и не настраивается: клиент видит в предпросмотре ровно
   то, что уйдёт, и запрет работает без дыр. Колонка `messenger_accounts.stop_line` остаётся в схеме, но больше не читается
   (удаление — двумя шагами по ADR-0005, [TASKS.md](../../TASKS.md)); `PATCH /partner/messenger/accounts/:id` поле `stopLine` не принимает.
   Ответ «СТОП» принимается, как и раньше.
3. **Страница «Счета и пополнение»** (`/money`, админ и поддержка): вкладки «Клиенты» и «Партнёры», остаток (у партнёра — «причитается»),
   поиск по названию, «Пополнить» в строке (только у админа). Карточки клиента и партнёра остаются.
4. **Основание пополнения необязательно** (`POST /clients/:id/deposit`, `POST /partners/:id/deposit`): пусто — «Ручное пополнение».
   У списаний и выплат основание обязательно. Кто пополнил, остаётся в журнале действий.
5. **Пункт «Лимиты» убран из меню партнёра** (лимиты звонков заводятся в тарифе, ADR-0080); адрес `/partner/limits` пока открыт —
   там снимаются прежние лимиты, пока их не перенесли в тарифы.
6. **«Записи разговоров» (объявление «слушаю записи») перенесены из «Денег» в «Аккаунт» партнёра.**

## Последствия

- Партнёр больше не может быть осторожнее площадки при включённой галочке: чтобы работать по своим лимитам, галочку снимают.
- Включённая по умолчанию галочка у всех аккаунтов означает: лимиты тарифов не действуют, пока профиль площадки задан ненулевым.
