# Architecture Decision Records

Каждое значимое решение — отдельный файл `NNNN-краткое-название.md` по шаблону
[`0000-template.md`](0000-template.md).

Зачем: через полгода никто (включая ИИ) не помнит, почему выбрано именно это.
ADR отвечает на «почему» и не даёт переигрывать решение по кругу.

Записывать решение, если оно: трудно обратимо, влияет на несколько модулей,
задаёт правило для будущего кода, или было выбрано из нескольких равных вариантов.

Статусы: `Предложено` → `Принято` → `Заменено ADR-NNNN` / `Отменено`.
Принятый ADR не редактируют — его заменяют новым.
