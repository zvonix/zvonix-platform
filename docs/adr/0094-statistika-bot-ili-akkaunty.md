# ADR-0094: Статистика «бот или аккаунты»

- **Статус:** Принято — 2026-10-22; владелец: «нужна статистика для админа и клиентов: какие клиенты перешли в бота, какие не стали,
  какие сообщения идут через бота, какие через аккаунты»
- **Дата:** 2026-10-22
- **Связано с:** [ADR-0077](0077-bot-max-vtoroy-kanal.md) (бот), [ADR-0088](0088-otchety-i-zashchita-akkauntov-max.md) (отчёты)

## Решение

- За период считаются только **ушедшие** сообщения (`sent`, `delivered`, `read`): «людей» — разные номера получателей, «в боте» —
  сколько из них **сейчас** подписаны на бота клиента и поделились номером (`bot_subscribers.state = 'started'`), сообщения —
  отдельно ботом и через аккаунты партнёров.
- Админ: блок «Бот или аккаунты» в «Отчётах MAX» (`routes` в `GET /messages/report`), строка на клиента.
- Клиент: строка над журналом сообщений за 7 суток (`GET /client/messages/route-stats?days=`).
- Считается запросом по `messages` и `bot_subscribers` за период; отдельных счётчиков не заводится.
