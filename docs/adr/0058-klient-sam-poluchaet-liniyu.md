# ADR-0058: Клиент сам получает линию

- **Статус:** Принято — 2026-09-30, решение владельца («делай что рекомендуешь»)
- **Дата:** 2026-09-30
- **Развивает:** [ADR-0052](0052-odin-vkhod-dva-kabineta.md) (кабинеты), настройка `clients.auto_approve`
- **Связано с:** [ADR-0014](0014-vybor-partnera-klientom.md) (клиент не видит партнёра)

## Контекст

Клиенты регистрируются без проверки (`clients.auto_approve`), но линию — SIP-подключение,
по которому клиент звонит, — заводил только администратор. Новый клиент («Корона»,
2026-09-30) получал кабинет, в котором звонить нечем, и должен был писать в поддержку.
Клиент — не только служба такси, но и человек, который звонит друзьям: ждать
администратора ему незачем.

## Решение

1. Клиент **сам заводит линию** в «Мои линии» кнопкой «Получить линию». Имя необязательно
   («Линия 1», «Линия 2»…). Линия создаётся сразу в состоянии `active`, а не `pending`:
   допуск клиента уже состоялся (человеком или настройкой), второй проверки нет.
2. Доступ SIP (имя, пароль, сервер) показывается **один раз**, как у администратора.
   Потерян — клиент **перевыпускает** его сам: старый перестаёт работать.
3. Пределы: не больше **5 линий** на клиента (постоянная в коде, не настройка); клиент
   не в состоянии `active` линий не заводит. Предел мягкий: два одновременных нажатия
   могут дать шестую линию, ущерба от этого нет.
4. Запись разговора и номер для показа задаёт площадка (как и раньше); клиент их
   при заведении не выбирает.
5. Приостановленную администратором линию клиент не оживляет: он создаёт и перевыпускает,
   но не меняет состояние.
6. Действия попадают в журнал (`channel.created`, `channel.credentials_reset`) с ролью
   вошедшего.

## Публичный контракт

- `POST /client/channels` `{ name? }` → `201 { channel, account }`
- `POST /client/channels/:id/credentials` → `{ account }` (чужая линия — `404`)

## Последствия

- Для первого звонка клиенту нужны ещё правило наценки (площадка) и деньги на счёте.
- Злоупотребление (много клиентов — много линий) ограничивает только допуск клиентов;
  если понадобится — предел на площадку отдельным решением.
