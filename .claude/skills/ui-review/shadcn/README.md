# Правила shadcn/ui — путеводитель

Копии правил официального навыка shadcn: [shadcn-ui/ui](https://github.com/shadcn-ui/ui),
каталог `skills/shadcn/rules/`, коммит `98a1fe67b439324ddc857f47fbdce056600a4329`
(MIT, © 2023 shadcn, текст — [LICENSE](LICENSE)), скопированы 2026-09-22. Порядок
копирования и обновления — [../../SOURCES.md](../../SOURCES.md).

Сам `SKILL.md` навыка **не взят**: при каждом вызове он запускает `npx shadcn@latest info`
— непроверенную версию пакета из сети. Компоненты ищутся через MCP-сервер `shadcn`
(подключён в `.mcp.json`), а правила ниже — это то, что из навыка стоило взять.

| Файл | О чём |
|---|---|
| [styling.md](styling.md) | Цвет только токеном, `gap` вместо `space-*`, `size-*`, `truncate`, без `dark:` и `z-index` на накладках |
| [composition.md](composition.md) | Заголовок у окна, группы у пунктов меню, выбор накладки |
| [forms.md](forms.md) | Поля формы, `aria-invalid` вместе с `data-invalid` |
| [icons.md](icons.md) | Иконки в кнопках: `data-icon`, без размеров внутри компонентов |
| [base-vs-radix.md](base-vs-radix.md) | Различия API; у нас **Radix** (`radix-ui`), значит `asChild` |

## Как применять у нас

- **Компонентов в проекте мало** — `apps/web/src/components/ui/`: окно подтверждения,
  кнопка, поле, подпись, переключатель, таблица (замер 2026-09-22). Правило про `Field`,
  `InputGroup`, `ToggleGroup`, `Badge`, `Card`, `Empty`, `Sonner` **не значит «завести
  компонент»**: новый компонент — решение по DESIGN.md («Техническая основа»), а находка
  здесь — только нарушение правила там, где компонент уже есть.
- **Тема.** У нас `data-theme` на корне и три состояния («как в системе» — без атрибута),
  а не класс `.dark` и `next-themes`, как предполагает shadcn. Палитра — из прототипа
  ([docs/DESIGN.md](../../../../docs/DESIGN.md), «Техническая основа»).
- **Замер 2026-09-22 по `apps/web/src`:** `space-y-`/`space-x-` — 0, `gap-` — 280,
  именных цветов (`bg-blue-`, `text-gray-`…) — 0, `dark:` — 13, ручной `z-` — 2.
  Кандидаты в находки — последние два числа.
