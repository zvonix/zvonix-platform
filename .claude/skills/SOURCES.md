# Чужие навыки и справочники

Всё, что Claude читает как инструкцию, в проекте проверено человеком или мной до того,
как попасть в репозиторий. Навык исполняется на машине разработчика: его текст — это
команды модели, а скрипты — команды оболочке. Поэтому чужой текст здесь не «ставится»,
а **копируется с закреплённой версией** (решение владельца 2026-09-22; порядок взят
из проекта CRM, где он уже опробован).

## Порядок

1. Только с согласия владельца — выбор записывается в [TASKS.md](../../TASKS.md).
2. Скачать файлы **по коммиту**, а не по ветке, во временный каталог, не в проект.
3. Проверить механически: скрытые символы Юникода, вставки вида «игнорируй прежние
   указания», команды установки и сети (`npx`, `curl`, `-g`), ссылки.
4. **Прочитать все файлы** до единого. Непрочитанный текст в `.claude/skills/` не кладётся:
   Claude Code подхватывает его сразу.
5. Не брать: хуки, скрипты, которые при каждом вызове ходят в сеть (`npx пакет@latest`
   в самом навыке), глобальную установку, «всегда последнюю версию».
6. Правка копии — с датой и причиной рядом с ней (раздел «Правки копии» или README
   каталога). Копия не правится так, чтобы исчезла находка: правило меняется из-за
   проекта, а не из-за экрана, который его нарушил.
7. Ссылки внутри копии не должны вести в нескопированное — иначе падает шаг гейта
   «Ссылки в доках».

**Обновление** — только вручную: посмотреть разницу между закреплённым коммитом и новым,
прочитать её, перенести, обновить коммит в таблице.

```bash
gh api repos/<владелец>/<репозиторий>/compare/<старый>...<новый> --jq '.files[].filename'
```

## Что рассмотрено и не взято (2026-09-22)

- **`frontend-design`** (Anthropic), **`taste-skill`**, **`ui-ux-pro-max`**, **`impeccable`** —
  задают новый стиль, а наш закреплён прототипом и [DESIGN.md](../../docs/DESIGN.md).
  У `impeccable` вдобавок хук, который скачивает исполняемый файл.
- **`SKILL.md` навыка shadcn** — при каждом вызове запускает `npx shadcn@latest info`,
  то есть исполняет непроверенную версию из сети. Взяты только правила.
  Не взяты и справочники `customization.md` (команды смены темы, класс `.dark` вместо
  нашего `data-theme`) и `chat.md` (компоненты чата, которых у нас нет).
- **Uxcel:** цвет, шрифты, иконки, композиция (`aesthetics`) и сетка (`layout-spacing-grids`) —
  по собственному правилу Uxcel они отключаются, когда у проекта своя дизайн-система;
  аудит доступности — его закрывают `accessibility` и `a11y-debugging`; экраны лендинга,
  цен, оплаты и все навыки продакт-менеджера — не про нас.
- **`superpowers`** целиком — хук при каждом запуске сессии и собственный обязательный
  порядок работы, который спорит с правилами [CLAUDE.md](../../CLAUDE.md).
- **Ревью-плагины, агенты Playwright, замеры навыков** — отложены владельцем, строка
  в [TASKS.md](../../TASKS.md).
